CounselMate began with a workflow problem: lawyers were losing time moving between fragmented sources of court information.

#### What the case study demonstrates

CounselMate connects customer discovery, MVP prioritization and hands-on execution. It is a practical example of the direction I want to take into product management: understand a specific workflow, choose the useful scope and build around the people doing the work.

### 10.4 Oracle self-service onboarding

**Category:** Enterprise product workflows  
**Title:** When self-service needs a simpler starting point.  
**Deck:** How hospital feedback changed the way identity policies were configured.  
**Byline:** Aditya Firoda

#### The original approach

Hospital IT teams needed to configure identity and access policies for Oracle Health. An API-first setup gave technically equipped teams a flexible way to do that work.

But the pilot revealed a difference between customer groups. Smaller hospitals did not always have the IT capacity or policy expertise needed to use the full configuration surface.

#### Changing the starting point

I used that feedback to add default-policy workflows. The change gave smaller teams a simpler starting point while retaining the broader capability for organizations that needed it.

This was a product decision about how different users could reach a useful result. More configuration options were not the complete answer; the setup also needed to fit the capabilities of the team using it.

#### Following the result

The revised self-service workflow reached more than 17 hospitals, and onboarding support requests fell by 23%.

The story connects pilot learning to a change in the experience and then to an operational outcome. It is one of the clearest examples of how my engineering work has included product judgment.

### Offline ArcGIS map

**Title:** Maps beyond the network.

During a DRDO traineeship, I built a Java desktop application using the ArcGIS Runtime SDK to work with maps offline.

The project introduced me to an important constraint in geospatial software: large map images need a more efficient representation than loading everything at once. Tile packages made it possible to work with the map in pieces.

**Title:** Three ways to find a word.

I explored inverted indexes, Boyer–Moore and Rabin–Karp using long-form text as the input.

An inverted index organizes where terms occur so later searches can use that structure. Boyer–Moore uses information about a pattern to skip possible positions during matching. Rabin–Karp uses rolling hashes to help compare candidate substrings.
